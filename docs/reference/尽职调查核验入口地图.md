## 分类口径

本表是唯一活动入口地图。「采集分类」与「优先级」按稳定 Source ID 合并自原适配台账，保留其历史研究分类，不根据入口名称或当前适配结果重新推断。原适配台账已删除，本表保留其逐 ID 分类与优先级；这些历史分类不作为当前能力声明。末尾新增来源的分类依据登记时观察到的入口形态，仍不代表全站验收。

采集分类描述当时已观察到的入口与内容渠道，不代表当前可访问性、生产支持或业务质量批准：

- **A**：静态正文或名单样本（34 条）。
- **B**：静态内容链接，详情待验（79 条）。
- **C**：公开参数查询/API 已取样（5 条）。
- **D**：输入/登录型入口（32 条）。
- **E**：动态/API/iframe 待适配（123 条）。
- **F**：本轮失败/限制，机制未知（136 条）；仅表示历史探测结果，不表示永久失效。
- **G**：入口可读，业务内容未定位（87 条）。
- **X**：页脚噪声（3 条），保留原始编号但不做 Source。

优先级沿用原台账的 `P0`、`P1`、`P2`、`暂缓`、`待复查`、`排除`，是历史研究建议，不是当前实施排期。采集分类与适配／审计状态独立，例如 B 类入口可能已有后续限定样本验收。
