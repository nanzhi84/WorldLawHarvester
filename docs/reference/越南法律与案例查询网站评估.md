# 越南法律与案例查询网站评估

测试日期：2026年10月11日

建议用“官方法律数据库＋法院裁判公开网＋最高法院判例网”作为核心，再用商业数据库补充检索。没有一个已核实的网站，能同时保证覆盖几乎全部法律和全部案件。

## 排序逻辑

按照以下优先顺序排列：**官方来源优先；同一权威等级内，先比较访问稳定性，再比较覆盖范围。**

|---|---|---|---|---|

## 使用时需要注意的事项

- **国家法律数据库要收藏新入口。** 司法部确认新版自2026年4月23日起在 `vbpl.vn` 正式运行。本次测试旧域名 `vbpl.moj.gov.vn` 无法解析，部分旧正文链接跳回首页，所以不建议继续依赖旧书签。[司法部上线公告](https://botruong.moj.gov.vn/portal/tin-tuc/chi-tiet/khai-truong-co-so-du-lieu-quoc-gia-ve-phap-luat-phien-ban-moi-te5qevfc56.html)
- **“全部案件”不能等同于“全部公开案例”。** 越南裁判公开规则设有不公开情形，涉及秘密、隐私保护等；因此，即使是法院官方数据库，也不能据此承诺覆盖所有案件。[裁判公开规定，第03/2017/NQ-HĐTP号决议](https://vbpl.vn/TW/Pages/vbpq-toanvan.aspx?ItemID=149080)
- **LuatVietnam的数量优势需要结合正文核对。** 本次抽查的一页标题和属性写的是 `627/2026/DS-PT`，正文开头却写 `583/2026/DS-PT`；该样本还存在原件、下载功能的账户限制。这不代表整个数据库都错误，但用于引用时应核对原件。两家网站统计口径也不同，不能直接把“140万”和“34万”当成覆盖率比较。[抽查页面](https://luatvietnam.vn/ban-an/ban-an-627-2026-ds-pt-2-1453936-d11.html)

## 实际使用建议

查法律时，以国家法律数据库检索范围为主，政府文件网和电子公报核对原件；查案例时，区分普通裁判与正式判例，分别使用两个法院入口，连接失败时再用两个商业案例库交叉检索。

## 测试方法与限制

本次做了三轮重复访问，累计 **66次只读连接测试**，并用浏览器核查检索及正文。结果只能说明**当前测试网络、短时观察下的可用性**，不能保证所有地区或长期连接稳定。

原报告引用的 `越南法律网站连接测试记录.json` 当前缺失，未随本报告归档。上文测试数量与结论保留为 2026-10-11 的历史报告内容；由于缺少逐次连接记录，不能在当前工作区独立复核，亦不代表当前网站可用性。
